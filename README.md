# Band Manager 

Профессиональный инструмент для музыкантов и саунд-продюсеров, позволяющий управлять процессом готовности написания, записи и сведения треков в одном интерфейсе.

## Проблема и решение

**Проблема:** При работе над музыкальным релизом демки разбросаны по разным папкам, параметры BPM забываются, а статус готовности (Mixing/Mastering) каждого трека сложно отслеживать в одном месте.
**Решение:** Приложение объединяет менеджер задач с аудиоплеером, позволяя мгновенно прослушивать локальные файлы, отслеживать прогресс и хранить метаданные трека.

---

## 🛠 Технологический стек

### Frontend
- **React 18 + TypeScript**: Основа приложения (функциональные компоненты).
- **TanStack Router**: Продвинутая типобезопасная маршрутизация.
- **Zustand**: Легковесный стейт-менеджер (выбран за минимализм и высокую производительность по сравнению с Redux Toolkit).
- **CSS Modules**: Изолированные стили компонентов.
- **Fetch API**: Нативное взаимодействие с бэкендом.
- **Lucide React**: Современный сет иконок.

### Backend
- **FastAPI (Python)**: Высокопроизводительный API-сервер.
- **Pydantic**: Валидация данных и схем.
- **StaticFiles**: Организация стриминга аудиофайлов напрямую из локальной библиотеки.

---

## 🏗 Архитектура проекта

Приложение построено по **слоистой архитектуре**:
1.  **API Layer (`src/api`)**: Инкапсулирует логику сетевых запросов.
2.  **Store Layer (`src/store`)**: Глобальное состояние и бизнес-логика (Zustand).
3.  **UI Layer (`src/components`, `src/routes`)**: Компоненты отображения и маршруты страниц.

Все данные о треках синхронизированы через Zustand Store, что исключает рассогласование данных между страницами «Главная», «Статистика» и «Детали трека».

## Запуск проекта

### 1. Подготовка
Убедитесь, что у вас установлены `Node.js` и `Python 3.10+`.

### 2. Backend
cd backend

pip install fastapi uvicorn aiofiles

В main.py укажите ваш путь к папке с музыкой (MUSIC_PATH)
```
MUSIC_PATH = "/home/as-eternum/Музыка/Demos" #вставить свой путь
```
python main.py

### 3. Frontend
Из корневой папки

npm install

npm run dev



### Структура папок

```
.
├── backend/                        # СЕРВЕРНАЯ ЧАСТЬ (FastAPI)
│   ├── main.py                     # Точка входа: роуты, CORS, монтирование статики (StaticFiles)
│   ├── repository.py               # Data Access Layer: логика хранения данных треков
│   ├── schemas.py                  # Pydantic модели: валидация входящих/исходящих данных
│   └── audio_files/                # Локальное хранилище или точка монтирования медиа-библиотеки
│
├── src/                            # КЛИЕНТСКАЯ ЧАСТЬ (React + TypeScript)
│   ├── api/                        # СЛОЙ ИНФРАСТРУКТУРЫ (API Client)
│   │   ├── api.ts                  # Сервис для HTTP-запросов (Fetch API)
│   │   └── types.ts                # Глобальные интерфейсы и типы данных (Contract)
│   │
│   ├── store/                      # СЛОЙ БИЗНЕС-ЛОГИКИ (State Management)
│   │   └── useTrackStore.ts        # Zustand Store: управление состоянием приложения и экшены
│   │
│   ├── components/                 # СЛОЙ ПРЕДСТАВЛЕНИЯ (UI Components)
│   │   ├── TrackCard.tsx           # Компонент карточки трека с плеером и контроллерами
│   │   └── TrackCard.module.css    # Изолированные стили карточки
│   │   
│   │
│   ├── routes/                     # СЛОЙ МАРШРУТИЗАЦИИ (TanStack Router)
│   │   ├── __root.tsx              # Базовый лейаут приложения (Navbar, Footer)
│   │   ├── index.tsx               # Главная страница: список треков и форма добавления
│   │   ├── stats.tsx               # Страница аналитики релиза
│   │   └── track.$trackId.tsx      # Динамический роут: детализация конкретного трека
│   │
│   ├── App.tsx                     # Конфигурация провайдеров и RouterProvider
│   ├── App.module.css              # Глобальные переменные и стили лейаута
│   └── main.tsx                    # Точка входа в React-приложение
│
├── tsconfig.json                   # Настройки компилятора TypeScript (Strict Mode)
```
